# Rosary Project Review - 2026-05-17

## Summary

The project is a lightweight static PWA for praying the Rosary and Divine Mercy Chaplet in Vietnamese and English. It is now also wrapped with Capacitor so the same app can be built for Android and iOS.

## Fixed In This Pass

- Added `package.json`, `package-lock.json`, and a repeatable `npm run build:web` build step.
- Added Capacitor Android and iOS projects.
- Changed the production web artifact to `dist/`.
- Changed Wrangler assets from repo root to `dist/` so native/build files are not deployed publicly.
- Vendored React, ReactDOM, Babel, and Tailwind browser runtime under `vendor/` to reduce CDN/offline risk.
- Added missing `icon-192.png` and `icon-512.png`.
- Replaced native app icons and splash assets with Rosary-branded images.
- Expanded the service worker cache to include local vendor files and mystery artwork.
- Renamed mystery artwork from `.png` to `.jpg` so file extensions match the actual JPEG image data.
- Disabled service worker registration inside the native Capacitor shell to avoid stale WebView cache issues.
- Added safer local persistence for settings and in-progress prayer state.
- Improved prayer progress calculation and added basic progress/image accessibility labels.
- Added reduced-motion support for users who prefer less animation.
- Added `PRIVACY.md` and `LICENSE`.

## Remaining Release Blockers

- Android APK build requires Java JDK and Android SDK/Android Studio. This server currently has no `java` command and no `JAVA_HOME`.
- iOS build requires macOS, Xcode, and CocoaPods. This Linux server cannot compile or archive the iOS app.
- App-store release should verify rights for all prayer text translations and mystery images.
- The app still uses browser-side Babel/Tailwind runtime. It now works offline because the files are local, but a future cleanup should move code into a real React/Vite build for faster startup.
- LocalStorage works for the current shell, but long-term native storage should move to Capacitor Preferences.

## Recommended Next Improvements

1. Move `index.html` inline React code into `src/App.jsx`.
2. Move mystery/prayer content into structured data with stable IDs, not translated display names.
3. Add optional local reminders with Capacitor Local Notifications.
4. Add accessibility pass: screen-reader labels, focus states, high-contrast checks, reduced-motion support.
5. Compress or convert mystery images to reduce app size.
6. Add tests for daily mystery selection, prayer progression, language switching, and session persistence.
