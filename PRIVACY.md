# Privacy

The Rosary app is designed to work without an account.

## Data Stored On Device

The app stores prayer settings and progress locally on the device:

- language
- theme
- font size
- selected prayer mode
- current in-progress step
- recent completion history
- prayer count, streak, and duration statistics

This data stays in the browser or native app storage. It is not sent to a server by this app.

## Network Use

The core prayer experience is bundled with the app and can work offline after install. The current app does not include analytics, ads, login, or third-party tracking.

## Notifications

The current version does not request notification permission. If prayer reminders are added later, they should be opt-in and handled with local notifications.

## Content And Assets

Prayer text and religious artwork should be reviewed before public app-store release to confirm content accuracy and distribution rights.
